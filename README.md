# Clothing pairing

作者：**Displaced** · 版本：**1.1.3** · **国服 Dalamud API 15 / .NET 10 / Windows x64**

本仓库 `lemon` 单独发布 Dalamud 独立版，插件名称和内部名仍为 **Clothing pairing / ClothingPairing**。已有安装时请改用下方订阅地址并保留配置，避免同时启用多个安装副本。

分别记忆玩家当前使用的一件时尚配饰和一件面部配饰，在已识别的中断结束、游戏允许且状态稳定后自动恢复。

## 功能

- 默认在离开副本后恢复；可选下坐骑、脱战和普通切区恢复。
- 面部配饰默认在切换职业或套装后缺失时恢复，支持同职业切换不同套装。
- 面部配饰保存完整款式与颜色 ID，仅记录一件；颜色不是额外槽位。
- 两类配饰独立开关、暂停、清除记忆及重试，按角色分别保存。
- 手动摘除后暂停对应项。重新佩戴或点击“继续 / 立即恢复”可解除暂停。
- 已佩戴的配饰优先：新套装有另一件面部配饰时采用当前款式，仍在佩戴时不重复操作。

采用“已识别中断后恢复”的 B 方案，不会持续强制佩戴。登录或重载插件不会自动执行旧记录。

## 安装

在 Dalamud 设置的自定义插件仓库中添加：

```text
https://github.com/Displaced5/lemon/releases/latest/download/repo.json
```

保存后刷新插件列表，搜索 **Clothing pairing** 并安装。升级时保留原配置，避免同时加载开发版和仓库版。

也可以从 [Releases](https://github.com/Displaced5/lemon/releases/latest) 下载 ZIP，解压到单独目录，在 Dalamud 的“开发插件位置”添加 `ClothingPairing.dll`。DLL、插件清单和 `.deps.json` 应位于同一目录。

首次使用请分别手动佩戴一次希望记住的配饰，再输入 `/cpair` 查看当前配饰、记忆和恢复设置。若命令已被占用，使用 `/clothingpairing`。

## 命令

| 命令 | 功能 |
|---|---|
| `/cpair` | 打开设置 |
| `/cpair pause` | 暂停两类配饰恢复，保留记忆 |
| `/cpair resume` 或 `/cpair restore` | 请求恢复两类记忆，仍受开关和游戏限制约束 |
| `/cpair clear` | 清除两类记忆，不移除当前配饰 |
| `/cpair face pause` / `resume` / `restore` / `clear` | 仅处理面部配饰 |
| `/cpair fashion pause` / `resume` / `restore` / `clear` | 仅处理时尚配饰 |

备用命令 `/clothingpairing` 支持相同子命令。

## 行为与边界

恢复前等待 1.2 秒连续可用；职业和套装变化还会先等待 1.5 秒稳定。请求提交后等待 2 秒确认实际佩戴，每类每轮最多提交 3 次；两类提交间隔至少 0.6 秒。副本内、战斗、骑乘、忙碌、剧情及状态不同步时等待，不强制修改模型或解锁状态，不修改和保存游戏套装。

职业和套装采用状态采样识别。重复应用同编号同职业的套装、仅编辑名称或内容、采样之间极短的切走又切回可能无法识别。主动摘除与切区、职业或套装切换重叠时存在意图歧义。

默认优先游戏自动雨伞，仅影响对应时尚配饰中的雨伞。附加动作姿势、装备幻化、宠物和坐骑不在功能范围内。

配置只记录配饰 ID、角色隔离所需的标识及暂停和触发设置。界面中的最近记录仅保留本次加载最近 80 条，不自动导出。接口异常时停止对应功能，可查看 `/xllog` 后重载检查。

配置版本为 2，升级保留原时尚配饰、面部配饰及暂停偏好。1.1.3 清理旧版虚设的面部第二项，保留实际佩戴位置的款式和颜色。

## 构建

需要 .NET SDK 10 和匹配的国服 Dalamud API 15 程序集。将仓库检出到以下布局，源码与所有编译产物分别存放：

```text
工作目录/
  源码/
    lemon/                本仓库
      src/                插件源码
      tests/              使用合成数据的离线检查
      packaging/          插件清单
      docs/               开发说明与更新记录
      build.ps1
  插件/
    lemon/
      .build/             obj、bin 和打包中间文件
      1.1.3.0/            插件文件
      ClothingPairing-1.1.3.zip
      repo.json           自定义仓库清单
```

在仓库目录运行：

```powershell
.\build.ps1 -DalamudDir '<Dalamud 程序集目录>' -DotnetPath 'dotnet'
```

也可用 `DALAMUD_HOME` 环境变量指定程序集目录。构建会运行离线检查、验证身份和版本，并按白名单打包。源码仓库及插件 ZIP 不包含宿主 DLL、PDB、玩家配置、日志或研究快照。OmenTools 仅作为接口参考，不是运行依赖。
